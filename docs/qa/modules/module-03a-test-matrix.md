## Execution boundary

`bingo_qa_test` is the guarded real MySQL 8.0.36 integration-test catalog. The QA backend ran with the documented `qa` profile on port 8081; the Android emulator connected through `10.0.2.2:8081`. Flutter analysis found no issues and the unit/widget suite passed 20/20. `bingo_qa` was used only for SELECT queries; see the [SQL](../evidence/module-03a-database-readonly.sql) and [result](../evidence/module-03a-database-readonly.txt).

Module 03A is **COMPLETE** for the supported registration design. All 20 requested scenarios were executed. Registration throttling is not implemented; the existing authentication throttle covers login only, and no signup throttle policy was added. Security review and executed tests found no role escalation, plaintext PIN storage, unapproved signup credit, or partial account on failure.
