# Module 02F — Master admin coverage matrix

## Method and status meanings

This inventory is reconciled against the React route map, backend controller mappings, Modules 02A–02E evidence, and the Module 02F real-browser run. A route render or controller test alone is not counted as execution evidence. `PASS` means the referenced action was executed and its outcome checked; `NOT RUN` means no end-to-end business action was performed; `BLOCKED` means a policy/production prerequisite prevents safe completion; `DEFERRED` has an explicit future owner; `NOT APPLICABLE` means no implemented admin capability exists.

Browser results apply to local QA only. Production financial settlement remains separately blocked. See [Module 02F audit](module-02f-final-admin-audit.md), [Chromium results](../evidence/module-02f-chromium-results.txt), [database reconciliation](../evidence/module-02f-database-reconciliation.txt), and the linked historical module evidence.

## Coverage totals and disposition

The matrix contains **44 action rows**: **32 PASS**, **6 NOT RUN**, **2 BLOCKED**, **3 DEFERRED**, and **1 NOT APPLICABLE**. Statuses are action-specific; QA simulation results do not imply production approval. Mandatory untested admin actions remain for finance-role revocation, agent PIN management, admin/support role transitions, and SUPPORT ticket mutations. Finance-role granting passed through the existing admin API, but no Admin Users UI control exists; Product must confirm whether API-only management is acceptable. These prevent Module 02 closure even though the high-risk tested flows passed.

Explicit later-module deferrals: live session progression, draws, claim creation/review, and entitlement creation belong to Module 03 because they depend on real ticket/gameplay integration. Ticket-bearing cancellation and refunds require Product/Finance rules and remain unsupported/blocked until those are approved. Production deposit/float/adjustment posting and prize settlement remain production-blocked independently of QA simulation results.
