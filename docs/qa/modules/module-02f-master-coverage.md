# Module 02F — Master admin coverage matrix

## Method and status meanings

This inventory is reconciled against the React route map, backend controller mappings, Modules 02A–02E evidence, and the Module 02F real-browser run. A route render or controller test alone is not counted as execution evidence. `PASS` means the referenced action was executed and its outcome checked; `NOT RUN` means no end-to-end business action was performed; `BLOCKED` means a policy/production prerequisite prevents safe completion; `DEFERRED` has an explicit future owner; `NOT APPLICABLE` means no implemented admin capability exists.

Browser results apply to local QA only. Production financial settlement remains separately blocked. See [Module 02F audit](module-02f-final-admin-audit.md), [Chromium results](../evidence/module-02f-chromium-results.txt), [database reconciliation](../evidence/module-02f-database-reconciliation.txt), and the linked historical module evidence.
