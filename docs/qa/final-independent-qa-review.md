## Decision summary

The follow-up MySQL/Mailpit integration tests and OpenAPI contract comparison passed using disposable, loopback-only Docker CLI containers; a clean backend build completed with all 85 tests passing and packaging successful from a temporary copy of the working source. This avoided the existing workspace JAR lock without stopping its owning process. The isolated services used port 13306 for MySQL and ports 1025/8025 for Mailpit; existing shared containers and port 3306 were not touched. A disposable MySQL dump/drop/restore rehearsal also succeeded and verified Flyway V13 plus 30 restored tables. The code review also identified production login-throttling and website-metadata risks; both remediations are implemented and their focused checks passed.

Production-specific backup retention and recovery objectives, five admin browser journeys, mobile-device financial/game journeys, the requested capacity/load test, production CloudFront association, and live operational monitoring remain unverified. A configured capacity of 1,000 players is not measured capacity. Do not approve real-money release or claim the 1,000-player target until the mandatory gates below pass.
